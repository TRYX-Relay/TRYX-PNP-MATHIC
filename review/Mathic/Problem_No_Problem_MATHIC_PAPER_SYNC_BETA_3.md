## 1. Governing Finite Semantic Formula Spine

For a current Boolean-valued state `f` and selected Boolean coordinate `x`, define the two current sibling restrictions

\[
a=f\vert_{x=0},\qquad b=f\vert_{x=1}.
\]

For Boolean inputs,

\[
\boxed{a\lor b=a+b-ab}.
\]

Define the existential fold

\[
\boxed{\mathcal E_x(f)=a\lor b}.
\]

Pointwise on every remaining address `r`,

\[
\boxed{
\mathcal E_x(f)(r)=1
\iff
\exists b\in\{0,1\}\;f(b,r)=1.
}
\]

Repeated over the finite carrier,

\[
\boxed{
R_n(f)=1
\iff
\exists a\in\{0,1\}^n\;f(a)=1.
}
\]

This establishes the finite semantic question under the declared representation. It does not by itself establish a deterministic polynomial-time algorithm in original CNF input length.
