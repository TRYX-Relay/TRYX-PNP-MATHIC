# Create the public destination

Create an empty public GitHub repository under TRYX-Relay named TRYX-PNP-MATHIC. Do not initialize it with a README, license, or gitignore; those decisions remain separate from the exported research content. Give the connected GitHub app access to this new repository, then provide its URL so the prepared files can be uploaded.

The archive contains the complete folder structure to upload. Upload the contents of TRYX-PNP-MATHIC, not the ZIP as the sole repository file. GitHub Actions will run the package check and the pinned proof pipeline after a push. Existing evidence is historical; wait for new runs before describing public-hosted verification as passed.
