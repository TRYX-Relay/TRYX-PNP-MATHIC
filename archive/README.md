# Historical PNP records

[Return to the current submission](../README.md)

These files are archived **in place** to preserve exact bytes, existing citations and restoration paths. They are not the current submission instructions. “Active,” “pending,” “locked,” or “awaiting” inside an old record describes that record's historical snapshot. The [current authority record](../submission/AUTHORITY.md) resolves present paper, figure, instrument and verification status.

The two local replay/oracle JSON files duplicate canonical benchmark outputs. Only the canonical outputs are members of the current submission; the duplicate receipts remain history. Beta papers, MATHIC sync drafts, setup instructions, build contracts and parked releases are not alternate current papers. The manual mixed-project workflow is retained for historical reproduction.

The published v1.0.0 release predates the approved paper. Its tag is preserved; use the current README and submission manifest for the September 18 edition.
